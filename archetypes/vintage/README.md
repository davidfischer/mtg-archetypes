# Vintage Archetypes

The archetype definitions in this directory are heavily based on the Vintage format data from [Badaro/MTGOFormatData](https://github.com/Badaro/MTGOFormatData), created and maintained by [IamActuallyLvL1](https://github.com/IamActuallyLvL1) (see [fork](https://github.com/IamActuallyLvL1/MTGOFormatData)).

The main difference should be just a preference for "new" color names (Sultai vs. BUG, Dimir vs. UB)

We also categorize archetypes into the following groupings:

- Bazaar
- Shops
- Combo
- Control
- Aggro

As of September 2026, these rules categorize over 99% of Vintage decks from MTGO over the last 2 years.
